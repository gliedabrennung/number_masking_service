# Проверка голосовых подсказок

Подсказки звучат в телефонном канале 8 кГц — именно там плохой синтез
превращается в кашу. Чтобы не полагаться на «вроде разборчиво», файлы
прогоняются через офлайн-распознаватель (Vosk, малая русская модель) и
сравниваются с исходным текстом.

```bash
make check-sounds
```

Вывод — по строке на подсказку: доля узнанных слов и что именно расслышал
распознаватель. Порог `ok` — 70 % слов; ниже считается неразборчивым.

Расхождения в окончаниях («проверите» вместо «проверьте») — артефакт малой
модели, а не дефект записи.

Сами файлы генерируются `make sounds` (Piper, голос `ru_RU-dmitri-medium`)
и коммитятся в репозиторий; образ Asterisk их только копирует.
